# OBG-Aid — Complete Clinical Content Specification

## 1. Purpose

OBG-Aid is a clinical reference application for **Obstetrics, Gynaecology, Reproductive Medicine, Maternal Medicine, Fetal Medicine and Gynaecological Oncology**.

The content should be organised around the questions an OBG clinician asks during:

- Antenatal care
- Labour and delivery
- Obstetric emergencies
- Postpartum care
- Gynaecology OPD
- Gynaecology emergencies
- Infertility and reproductive medicine
- Fetal medicine
- Gynaecological oncology
- Urogynaecology
- Menopause care
- OBG procedures and surgery
- Academic examination and postgraduate learning

The objective is not to create a textbook. The objective is to provide **rapid, structured, evidence-linked clinical reference content**.
